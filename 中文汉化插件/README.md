# 中文汉化插件

这个目录现在只保留一个用户入口：

```text
一键汉化.py
```

其余规则、翻译记忆、扫描和验证工具都放在 `内部/`，平时不需要管。

## 用途

这个插件用于把 **VideoHighlighter 官方源码** 转成中文版源码。

它不是给已经打包好的 EXE / 便携版直接修改用的。

## 使用方法

把 `中文汉化插件/` 放在 VideoHighlighter 源码根目录，然后运行：

```powershell
python "中文汉化插件/一键汉化.py" --root . --strict
```

如果目标不是源码目录，脚本会停止，不修改文件。

## 目录

```text
中文汉化插件/
├─ 一键汉化.py
├─ README.md
└─ 内部/
   ├─ 汉化规则.json
   ├─ 翻译记忆库.json
   ├─ 保留英文白名单.json
   ├─ 扫描遗漏英文.py
   ├─ 验证汉化完整性.py
   ├─ 重建汉化规则库.py
   └─ 资源/
      └─ ChineseSimplified.isl
```

普通使用中文版不需要运行这里的任何工具，直接下载本仓库中文版即可。
