# VideoHighlighter 中文汉化插件

这是整个中文本地化系统的独立目录。以后维护汉化时，主要看这个文件夹即可。

## 目录结构

```text
中文汉化插件/
├─ 一键植入中文.py
├─ 扫描遗漏英文.py
├─ 验证汉化完整性.py
├─ 重建汉化规则库.py
├─ 数据/
│  ├─ 汉化规则.json
│  ├─ 翻译记忆库.json
│  └─ 保留英文白名单.json
├─ 资源/
│  └─ ChineseSimplified.isl
└─ 报告/
```

## 最常用

### 给官方源码植入中文

```powershell
python "中文汉化插件/一键植入中文.py" --root . --strict
```

### 扫描新增或遗漏英文

```powershell
python "中文汉化插件/扫描遗漏英文.py" --root .
```

### 官方更新后重建规则库

```powershell
python "中文汉化插件/重建汉化规则库.py" --upstream-ref upstream/main
```

## 工作逻辑

- 汉化规则绑定具体文件和源码块，不做全局暴力替换。
- 内部枚举、API、配置键、协议字段继续保持英文。
- 官方文本发生变化时，不强行套旧翻译，而是标记 changed / missing。
- 翻译记忆库保存已经确认过的英文 → 中文映射。
- Windows 安装器中文语言资源也一起放在本目录。
- 生成报告统一放在“报告”目录。

这个文件夹可以作为独立的中文本地化层，跟随官方源码持续更新。
