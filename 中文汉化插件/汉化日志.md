# 汉化日志

这里记录的是 **VideoHighlighter-CN 的中文本地化改动**，不是上游官方项目的原始开发日志。

## 2026-10-05

### 汉化系统
- 建立独立的 `中文汉化插件/` 目录。
- 将汉化规则、翻译记忆库、英文白名单、安装器中文资源统一收拢。
- 增加一键植入中文、扫描遗漏英文、验证汉化完整性、重建汉化规则库等工具。
- 汉化注入采用文件级精确匹配与上下文判断，避免全局暴力替换。
- 内部枚举、API、配置键、协议字段继续保持英文，防止破坏程序逻辑。

### 界面汉化
- 完成主程序、时间线、模型中心、训练、LLM、视觉搜索、下载、转录、设置等主要界面汉化。
- 完成 React/TSX 前端主要页面汉化。
- 完成 Windows Inno Setup 安装器简体中文化。
- 补齐大量按钮、标签、提示、弹窗、状态栏、工具提示与动态状态文本。

### 验证
- 建立“中文汉化层验证”CI。
- 已验证可从干净官方源码重新应用汉化规则。
- 已验证主要汉化文件可被本地化层完整重建。
- 已通过 Python 测试、前端 Lint、TypeScript 检查和前端 Build。
- Windows 打包、安装和安装后冒烟测试已通过。

### 持续维护
- 增加遗漏英文扫描器。
- 增加翻译记忆库，后续官方更新时优先复用已有翻译。
- 官方更新后仅需处理 changed / missing 等新增或变化项，不再重新人工汉化整个项目。

---

> 上游官方自身的版本历史、功能开发和原始变更记录，仍以官方仓库为准；本日志只记录中文版和汉化系统的变化。
